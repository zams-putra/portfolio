## step :
- tinggal :
```bash
netlify login
netlify link
[set ke project name, taruh aja]
npm run build

```



## Features
- Terminal
- Blog (pisah disini biar enak: github.com/zams-putra/blog-portfolio)
- Music player
- 3D Objects
- Motion Animation
- Pagination
- AI chatbot
- Visitor Tracking (google analytic)
- Visitor Blog Article (redis upstash)
- XML Sitemap (vite-plugin-sitemap)
